# Krusty Phish Shield - Anti-Estafas MX

Detector defensivo de URLs sospechosas para México.

Verifica sin entrar a la página. Todo local, sin guardar datos.

### Ético
- No hace requests a la URL sospechosa
- Análisis solo de patrones
- No guarda URLs
- Todo local

### Uso
python main.py

### Detecta
- IPs en vez de dominio
- Técnica del @
- Typosquatting (bbva-seguro-urgente.tk)
- TLDs sospechosos
- Falta de HTTPS
